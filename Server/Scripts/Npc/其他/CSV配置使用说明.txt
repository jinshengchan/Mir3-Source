装备回收CSV配置使用说明
========================

概述
----
现在装备回收系统支持使用CSV文件进行配置，这样可以更方便地管理和修改回收列表。
系统会优先读取CSV文件，如果CSV文件不存在或读取失败，会自动使用Python配置文件作为备用。

文件结构
--------
1. 回收配置.csv - CSV格式的装备回收配置文件
2. 回收配置.py - Python格式的备用配置文件
3. 回收配置管理工具.py - CSV配置管理工具

CSV文件格式
-----------
CSV文件应包含以下列：
- 装备名称: 装备的完整名称
- 回收价格: 回收该装备获得的金币数量
- 装备类型: 装备的分类类型（可选）

示例：
装备名称,回收价格,装备类型
匕首,100,武器
井中月,14000,武器
银蛇,5000,武器
轻型盔甲（男）,2500,防具
金项链,100,首饰

使用方法
--------

1. 生成CSV文件
   运行以下命令从Python配置生成CSV文件：
   python 回收配置管理工具.py generate

2. 验证CSV文件
   检查CSV文件的格式和内容是否正确：
   python 回收配置管理工具.py validate

3. 添加新装备
   向CSV文件添加新的装备：
   python 回收配置管理工具.py add "新装备名称" 1000
   python 回收配置管理工具.py add "新装备名称" 1000 "武器"

4. 移除装备
   从CSV文件中移除装备：
   python 回收配置管理工具.py remove "装备名称"

5. 更新装备
   修改装备的回收价格和类型：
   python 回收配置管理工具.py update "装备名称" 2000
   python 回收配置管理工具.py update "装备名称" 2000 "防具"

管理工具命令
------------
- generate: 从Python配置生成CSV文件
- validate: 验证CSV文件格式和内容
- add <装备名称> <回收价格> [装备类型]: 添加新装备
- remove <装备名称>: 移除装备
- update <装备名称> <新价格> [新类型]: 更新装备
- help: 显示帮助信息

注意事项
--------
1. CSV文件必须使用UTF-8编码
2. 装备名称必须完全匹配游戏中的名称
3. 回收价格必须是正整数
4. 装备类型是可选的，用于分类管理
5. 修改CSV文件后，需要重启服务器才能生效
6. 如果CSV文件损坏或格式错误，系统会自动使用Python配置

优势
----
1. 易于编辑：可以用Excel或其他表格软件编辑
2. 版本控制友好：CSV文件便于版本控制
3. 批量操作：可以批量导入/导出装备列表
4. 可视化：可以用表格软件直观查看和编辑
5. 分类管理：支持装备类型分类，便于管理
6. 备用机制：CSV文件有问题时自动使用Python配置

故障排除
--------
1. 如果CSV文件无法读取，检查文件编码是否为UTF-8
2. 如果装备无法回收，检查装备名称是否完全匹配
3. 如果价格显示错误，检查CSV文件中的数字格式
4. 如果系统报错，运行验证命令检查CSV文件格式

技术支持
--------
如果遇到问题，可以：
1. 运行验证命令检查配置
2. 查看服务器日志文件
3. 重新生成CSV文件
4. 使用Python配置作为备用方案
