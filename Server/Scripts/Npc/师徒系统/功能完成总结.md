## 技术实现细节

### 核心功能
1. **师徒值管理**：使用`BV_SHITU_BONUS`变量存储玩家师徒值
2. **物品兑换**：通过`Sender.GiveItem()`和`GiveGold()`函数给予物品
3. **背包检查**：使用`GetInventoryCount()`检查背包空间
4. **NPC跳转**：通过创建新的NPC实例实现菜单跳转
