# 八大暗影接入活动管理员设计

## 目标

将八大暗影入口从独立 NPC 5656 移至现有“活动管理员”（NPC 332），并保留活动管理员与八大暗影各自已有功能。

## 方案

1. 在活动管理员主菜单增加“八大暗影”入口。
2. 使用未被现有活动管理员占用的菜单编号：80（打开）、81（开始挑战）、82（刷新状态）。
3. 活动管理员仅负责将这三个菜单编号转交给八大暗影原有逻辑；八大暗影的收费、地图、怪物、奖励、并发和每日限制均不改动。
4. 取消八大暗影原有的 NPC 5656 点击事件绑定；由于同一 NPC 的同一事件只能保留一个监听器，八大暗影不能直接再绑定到 332。实际点击入口由活动管理员统一处理，八大暗影继续保留副本地图事件。

## 最小改动文件

- `D:\Debug\4月18日更新\Server\Scripts\Npc\活动管理员.py`
- `D:\Debug\4月18日更新\Server\Scripts\Npc\BOSS副本\八大暗影.py`
- `D:\相聚假人\Source\CHANGELOG.md`

修改前只备份上述将被覆盖的文件。

## 验证标准

1. 静态检查确认活动管理员是 NPC 332，且主菜单含八大暗影入口。
2. 静态检查确认 80/81/82 菜单编号均由活动管理员转交，八大暗影不再绑定 5656。
3. IronPython 2.7 语法检查通过。
4. 服务端重载脚本后，点击活动管理员可打开八大暗影说明；点击开始挑战仍按原规则扣除 500 元宝并进入副本。
