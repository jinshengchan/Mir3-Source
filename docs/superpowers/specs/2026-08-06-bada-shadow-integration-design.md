# 八大暗影脚本接入设计

## 目标

将 `D:\Video\八大暗影.py` 接入当前服务端脚本系统，并保持脚本原有副本流程、NPC 菜单、地图事件、每日限制、并发池和奖励不变。费用按本次确认调整为入口 500 元宝、每层 50 元宝。

## 接入位置

- 目标脚本：`D:\Debug\4月18日更新\Server\Scripts\Npc\BOSS副本\八大暗影.py`
- 自动加载：在同目录 `__init__.py` 增加 `import Npc.BOSS副本.八大暗影`
- 加载链路：`main.py` 加载 `Npc` → `Npc\__init__.py` 加载 `Npc.BOSS副本` → BOSS 包初始化加载八大暗影脚本。
- 事件占用：NPC 5656；副本地图 387。接入前已确认目标脚本目录没有相同 NPC 事件或地图事件注册。

## 费用行为

- 入口费用：`BADA_ENTER_COST = ("元宝", 500)`，使用 `SubGameGold` 扣减 `GameGold`。
- 层费用：`BADA_LEVEL_COST = ("元宝", 50)`，在每次 `InitNewLevel` 开始前检查并扣减 50 元宝，包含第一层和后续层。
- 元宝不足：不生成该层，提示玩家并按脚本原有回城/关闭副本路径处理；不扣除不足的费用。
- 入口失败（副本创建失败或等待队列已满）：使用 `GiveGameGold` 退还入口费用并触发客户端余额刷新。

## 明确不改动

- 不改 NPC 菜单编号、地图坐标、怪物顺序、奖励、每日次数、排队容量和刷新锁。
- 不重构进程池，也不修正原脚本已有的重复释放逻辑；这些属于后续独立修复范围，避免偏离“严格原样接入”。
- 不修改 `Scripts888`、客户端或服务端 C# 源码。

## 验证

1. 目标脚本包导入契约：文件存在、BOSS 包初始化包含导入、事件编号和地图编号保持正确。
2. 费用契约：入口/层费用为 500/50，扣费和退款使用元宝函数。
3. Python 2.7 语法编译检查。
4. 记录覆盖前备份和更新日志；完成后由服务端重新加载脚本，再观察“加载脚本成功”和八大暗影事件注册日志。
