# PC 装备悬停共用外框与魔法技能窗口修复设计

## 目标

1. 将人物/装备外观和物品属性放入同一个悬停外框，使用一条竖线分隔。
2. 恢复魔法技能窗口完整宽度、完整分类按钮和技能页面，修复右上角覆盖、错位及显示不全。

## 装备悬停共用外框

### 结构

- 使用现有外观预览控件作为统一外层容器。
- 外层容器统一绘制深色半透明背景和细金色外边框。
- 左区保持现有人物/装备外观绘制；宽度继续按素材实际范围计算，左右各保留 `6` 像素。
- 右区承载原 `ItemLabel` 的全部属性子控件，不改变文字内容、字体、颜色和纵向位置。
- 左右区域之间只绘制一条 `1` 像素金色竖线，不再分别绘制两套边框。

### 尺寸与定位

- 共用外框宽度为：左区宽度 + `1` 像素分隔线 + 右区原宽度。
- 共用外框高度为左区原始高度与右区属性内容高度中的较大值。
- `ItemLabel` 作为共用外框的子控件放在分隔线右侧，关闭自身背景和边框，只保留原有文字子控件。
- 右侧“身上装备/属性差值”比较面板继续作为独立面板显示在共用外框右侧，间距保持 `4` 像素。
- 无外观预览的非装备物品继续使用原独立物品说明框。

## 魔法技能窗口修复

### 已确认根因

- 当前 `MagicDialog.cs` 未启用正确版本中的额外 `30` 像素窗口宽度。
- 格斗、刺杀、暗杀三个分类按钮和对应页面缺失。
- 火、冰、雷、风、神圣、暗黑、幻影、武器技能八个按钮被整体右移，最后按钮进入右上角边框区域。
- 当前基础页面素材为 `1622～1636`，正确完整版本使用扩展页面素材 `1711～1718`，并补充 `1741～1743` 三个职业技能页面。

### 恢复范围

- 以 `MagicDialog.cs.bak-rollback-20260730-2355` 为正确参考，但禁止整体覆盖当前文件。
- 定点恢复额外 `30` 像素宽度、右侧背景延伸、关闭按钮位置和11个分类按钮坐标。
- 恢复 `Combat`、`Assassination`、`Assassinatie` 三个按钮、三个页面、点击切换、可见性切换、滚轮处理和释放逻辑。
- 八个基础技能页面改回扩展素材 `1711～1718`；三个新增页面使用 `1741～1743`。
- 保留当前文件与上述显示范围无关的代码，不修改技能数据、学习规则、服务端或封包。

## 验证标准

### 装备悬停

- 外观与属性只有一个完整外边框。
- 中间只有一条竖向分隔线，没有双边框和间隙。
- 人物/装备不缩放、不裁切；左右区域上下对齐。
- 原属性说明和右侧装备差值比较继续正常显示。

### 魔法技能窗口

- 顶部完整显示11个分类按钮，最后按钮不被右上角边框或装饰覆盖。
- 窗口背景、右边框、滚动条和关闭按钮与扩展宽度一致。
- 格斗、刺杀、暗杀三个页面可点击切换，并显示相应技能树。
- 八个基础分类继续正常切换、滚动和显示。
- PC 客户端编译成功；覆盖源码和目标客户端前分别备份，并补充更新日志。
