# PC 双游戏界面设计规格

## 目标

在同一份 PC 客户端中保留现有“145界面”，并新增与用户提供的 1024×768 参考图一致的“韩版界面”。登录界面提供“145界面／韩版界面”两项互斥选择；选择写入 `Mir3.ini`，进入游戏前读取并只构造对应的一套游戏界面。

## 已确认的视觉要求

- “145界面”必须保持当前素材、布局、点击区域和功能行为不变。
- “韩版界面”必须使用源码现有资源库中与参考图一致的素材，不以近似配色、简单换背景或现有 `UI2.Zl` 全局替换代替。
- 韩版 1024×768 基准布局必须与参考图一致：底部横向状态栏、左下聊天与快捷栏、右侧竖向主菜单、右上小地图，以及韩版角色窗口和背包窗口。
- `GameInter.Zl`、`GameInter2.Zl`、`Interface.Zl` 等现有资源可按实际索引组合；`UI2.Zl` 只使用其中确实匹配参考图的素材。不得假设 `UI2.Zl` 与 `UI1.Zl` 索引兼容。
- 不覆盖或破坏现有素材包。需要新增组合资源时使用新的独立资源文件名，并记录来源索引；覆盖部署文件前必须备份。

## 架构

### 1. 配置与登录选择

- 在 `Client.Envir.Config` 的 `Graphics` 配置节新增一个单值界面选项，值域仅为 `145` 和 `Korean`，默认值为 `145`，保证旧 `Mir3.ini` 与当前玩家无行为变化。
- `LoginScene` 增加两个互斥按钮，文字固定为“145界面”和“韩版界面”。当前配置对应按钮显示选中状态。
- 点击后立即更新内存配置并调用现有配置保存机制写入 `Mir3.ini`；不得改动 IP、端口、分辨率等其他配置项。
- 登录和选角场景继续使用现有登录素材，界面选择只影响进入游戏后的 `GameScene`。

### 2. 构造时机与生命周期

- `LoadScene.CreateGame()` 是主题选择的锁定点。创建 `GameScene` 前读取已保存的界面选项，并把选项传入或交由 `GameScene` 构造阶段读取。
- 每次进入游戏只创建一套主题控件；不得先创建 145 控件再隐藏后叠加韩版控件，也不得在游戏运行中替换已创建控件的资源库。
- 改变选择后，下次进入游戏生效。游戏内不新增热切换按钮，避免现有控件缓存的尺寸、纹理和点击区域失效。

### 3. 共享逻辑与主题视图

- 网络封包、人物数据、背包数据、技能数据、聊天数据、按钮命令和快捷键继续使用现有逻辑。
- 主题差异限制在视图构造、素材索引、尺寸、坐标、锚点和可见控件组合。
- 对需要两套布局的核心控件，新增韩版视图实现或在现有控件内部建立一个小型、明确的主题分支；不得把全项目的 `LibraryFile.UI1` 机械替换成另一资源库。
- 优先复用现有控件事件和公开字段，避免复制网络/业务处理代码。若 `GameScene` 的既有字段被其他逻辑直接引用，韩版实现必须保持兼容的字段或接口。

### 4. 第一阶段必须覆盖的韩版界面

以下内容共同构成可交付的第二套游戏界面，不能只完成主面板：

1. 底部主状态栏：HP、MP、等级、职业、经验/负重信息、属性摘要和功能按钮。
2. 左下聊天区：频道页签、消息区、输入区及其滚动/点击区域。
3. 左下快捷物品栏：格子、数量、拖放和快捷键行为。
4. 右侧主菜单：与参考图一致的竖向按钮排列，复用当前各功能入口。
5. 右上小地图区域：保持地图逻辑，仅按韩版素材和布局定位。
6. 角色窗口：使用参考图中的韩版外框、页签、装备位和人物预览布局；保留当前装备外观、属性说明和对比功能。
7. 背包窗口：使用参考图中的韩版外框、格子、负重/货币区和按钮布局；保留当前 8×8、滚动、搜索、刷新及物品交互功能。
8. 与核心界面直接联动且可见的通用窗口边框、按钮和页签，使用韩版素材；未在参考图中出现的业务窗口不得删除功能，可继续复用现有业务布局，但主题外框必须一致。

## 分辨率策略

- 1024×768 为像素级基准验收分辨率。
- 其他分辨率沿用现有窗口锚定规则：底部组件贴底、右侧组件贴右、地图视野占用剩余区域；不得通过整体拉伸造成素材变形。
- 最低支持当前客户端已有的最小游戏分辨率。若空间不足，优先保持按钮可点击、窗口不越界，不隐藏现有功能。

## 兼容与失败处理

- 配置缺失、空值或未知值一律回退到 `145`。
- 韩版专用资源缺失或打开失败时，在创建 `GameScene` 前回退到 145 界面并写入日志，不能进入黑屏或半套界面状态。
- 两个主题共用同一服务器协议和数据库，不修改服务端。
- 不改安卓客户端，不改变服务器配置，不改与双界面无关的功能。

## 验收标准

1. 首次使用旧配置启动时默认 145 界面，画面和功能与改动前一致。
2. 登录界面能清楚选择“145界面”或“韩版界面”，重启客户端后选择仍保留在 `Mir3.ini`。
3. 选择韩版后进入游戏，1024×768 下整体布局和素材与参考图一致，且只构造韩版主题控件。
4. 两套界面的聊天、快捷栏、角色、背包、小地图和右侧功能按钮均可点击并执行原有功能。
5. 在两种选择下分别登录、退出到角色界面、重新进入游戏，不出现黑屏、重复控件、残留点击区或资源异常。
6. `145Client\145Client.csproj` 使用 VS 2022 Build Tools 的 MSBuild 完整重建成功，0 error。
7. 覆盖 `D:\Debug\4月18日更新\Client` 中已有文件前生成逐文件备份，并在根目录 `CHANGELOG.md` 记录源码、资源、配置和部署改动。

## 不在本次范围

- 游戏运行中的即时热切换。
- 安卓端主题切换。
- 服务端协议或数据表变更。
- 与参考韩版布局无关的新功能、窗口重构或素材重绘。
