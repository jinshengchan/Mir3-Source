# PC 韩版聊天贴边与怪物窗口主题隔离设计

## 目标

修正两个已由实机截图确认的回归：韩版聊天记录区与输入框之间存在空隙；韩版怪物信息窗口的外观和行为错误地影响了145界面。

## 已确认根因

- `GameScene.SetDefaultLocations()` 与 `ChatDialog.Korean.ApplyKoreanChatSize()` 都在原有贴边坐标上额外减去 8 像素，导致聊天记录外框与输入框之间出现可见空隙。
- `MonsterDialog` 是145和韩版共用的单一实现。韩版新增的200×160可移动窗口、三角展开、70%背景和9F文字没有界面模式保护。
- `GameScene.Process()` 中新增的“移动/推动时隐藏、停止后恢复、鼠标移出不清空”逻辑也没有界面模式保护。
- `D:\相聚\145Client\Scenes\Views\MonsterDialog.cs` 与同目录 `GameScene.cs` 保存了145原始窗口与原始显示行为，可作为恢复基线。

## 实现方案

### 聊天布局

- 用户通过可拖动示范确认三个全局相对位置：聊天记录框 `(20,18)`、380×38金色输入底框 `(20,186)`、295×20实际文字输入区 `(20,224)`；其核心关系是记录框底边等于金色底框顶边，文字输入区紧接金色底框下方，三者左边对齐。
- 撤销两处额外的 `-8`，使韩版聊天记录外框底边与金色底框顶边使用同一Y边界。
- `ChatTextBox` 内部仅韩版调整为：`GameInter/3503 Background=(0,0,380,38)`，`DXTextBox=(0,38,295,20)`，总布局高度58；整个输入组合底边紧贴 `MainPanel.DisplayArea.Top`。
- 左侧切换聊天按钮保留在金色底框 `(0,0)`，右侧三角按钮保留在 `(356,0)`。
- 聊天记录区的黑色背景、文字面板和滚动条都延伸到聊天窗口底边，不能只让外层坐标贴合而在内部保留2像素透明空行。
- 3503背景必须真正置于左侧模式按钮和右侧三角按钮之后绘制，避免覆盖或压暗按钮。
- 不修改四级缩放、隐藏循环、透明度、滚动条、提示、关闭按钮或聊天业务逻辑。

### 怪物窗口

- 保留现有 `MonsterDialog` 公共类型和 `Monster`、`RefreshHealth()`、`RefreshStats()` 接口，避免扩大调用方改动。
- 构造时读取 `GameScene` 已锁定的 `KoreanInterface`：
  - 145界面构造 `D:\相聚\145Client` 中的原始240×120头像式窗口；
  - 韩版界面构造当前200×160可移动、可折叠窗口。
- 两种布局共用怪物数据赋值和属性刷新入口，布局控件各自初始化。
- `OnMonsterChanged()` 的定位规则按界面隔离：145恢复原定位；韩版保留首次居中后可拖动的位置。
- `GameScene.Process()` 的移动隐藏、停止恢复和鼠标移出保留仅用于韩版；145恢复原来的鼠标移出即隐藏逻辑。
- 韩版怪物窗口外层只绘制金色边框，不先绘制一层不透明底色；70%深色背景由唯一的内容层负责。

## 验收标准

- 静态契约证明两处聊天定位不再包含额外8像素间隙。
- 静态契约证明韩版金色底框、实际文字输入区和58像素总高度符合用户示范，145输入框不变。
- 静态契约证明聊天内部区域没有2像素视觉空隙、3503位于按钮之后、怪物背景实际为70%。
- 145分支具备原始240×120布局、原始定位、不可移动及鼠标移出隐藏行为。
- 韩版仍具备200×160布局、可移动、三角折叠、70%内容背景、9F文字和移动时隐藏行为。
- Release Rebuild 0 errors；既有回归契约全部通过。
- 只覆盖部署目录中的 `Mir3.exe`，覆盖前不再重复备份；`Mir3.ini` 哈希保持不变。
- Direct3D外观和交互由用户实机确认，不用静态契约冒充视觉验收。
