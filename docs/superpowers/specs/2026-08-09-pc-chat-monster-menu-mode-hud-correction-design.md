# PC 聊天、怪物信息、韩版主菜单与模式栏修正设计

## 目标

在不修改资源包、服务端或移动端的前提下，对 PC 客户端完成四项外科手术式修正：

1. 去除韩版聊天输入栏上方残留的复合素材阴影，并给最左侧聊天模式按钮增加“切换聊天”提示。
2. 将鼠标指向怪物时显示的信息窗口调整为参考图的紧凑深色金边样式，并允许拖动。
3. 完善韩版主菜单标题与按钮功能。
4. 在韩版底部 `IP` 行显示人物攻击模式和宠物控制模式。

## 范围

生产源码预计只涉及：

- `145Client/Scenes/Views/ChatTextBox.cs`
- `145Client/Scenes/Views/MonsterDialog.cs`
- `145Client/Scenes/Views/MainPanel.Korean.cs`

仅当实际编译暴露必要性时，才允许对直接调用点做一处最小适配。不得修改 `.ZL`、`Mir3.ini`、服务端、移动端、网络配置或 145 主界面布局。

按用户最新要求，在正式实机确认前不重复创建源码、部署文件或更新日志备份；保留现有备份不动。每轮实际部署仍追加 `CHANGELOG.md` 记录，并明确标注待实机确认。

## 1. 韩版聊天输入栏

### 根因

`GameInter/3503` 实际尺寸为 380×38。当前以 380×25 从素材顶部绘制，因此保留了素材顶部约 8 像素的复合阴影。最左侧 `ChatModeButton` 没有悬停提示。

### 设计

- 韩版继续复用 `GameInter/3503`，不生成或修改资源。
- 通过父控件裁剪，将素材向上偏移 8 像素，只显示输入栏主体区域，去掉顶部阴影。
- 独立三角按钮同步对齐裁剪后的内嵌按钮位置，继续保证画面中只有一个有效三角按钮。
- 保留现有四级缩放、隐藏恢复和消息输入业务逻辑。
- `ChatModeButton.Hint` 设为精确文本 `切换聊天`；145 与韩版共用该提示，不改变点击切换聊天频道的行为。

### 验收

- 韩版输入栏上方不再出现额外深色横向阴影。
- 输入框、最左侧聊天模式按钮和右侧三角按钮均可点击。
- 最左侧按钮悬停显示“切换聊天”。
- 右侧三角仍按既有状态显示“缩小聊天框／隐藏聊天框／展开聊天框”。

## 2. 怪物悬停信息窗口

### 现状与根因

现有 `MonsterDialog` 已由鼠标悬停怪物驱动，且 `Movable=true`，但窗口仍为 310×85 的横向头像布局；每次切换怪物都会重新居中，导致拖动位置无法保持。

### 设计

- 保留现有 `GameScene` 悬停赋值、显示隐藏、血量刷新和数据字典流程。
- 窗口调整为约 200×160 的紧凑深色金边布局，不显示怪物头像。
- 内容与参考图一致：
  - 顶部：等级、怪物名称。
  - 第二行：元素／体质图标、红色血条和当前／最大生命。
  - 中部两列：物防、魔防、物攻、魔攻。
  - 底部两行：体质、火、冰、雷、风、神圣、暗黑、幻影八项抗性图标和值。
- 属性优先使用 `ClientObjectData.Stats`；未取得动态数据时回退到 `MonsterInfo.Stats`。
- 物防、魔防、物攻、魔攻分别使用 `MaxAC`、`MaxMR`、`MaxDC`、`MaxMC` 的现有 `GetFormat` 范围格式。
- 复用现有 `GameInter/1517`、`1520` 至 `1526` 元素图标和现有血条绘制，不新增素材。
- 首次出现时仍置于屏幕顶部中央；用户拖动后，本次游戏场景生命周期内切换或移开怪物不再重置位置。退出客户端后不保存位置，不写入 `Mir3.ini`。

### 验收

- 鼠标指向普通怪物时显示参考图结构的信息窗口，移开时隐藏。
- 怪物名称、等级、生命、四项攻防和八项抗性均来自现有数据。
- 窗口可拖动；换怪或移开再指向后保持本次登录中的拖动位置。
- 不改变攻击目标、鼠标命中或怪物数据封包逻辑。

## 3. 韩版主菜单

### 根因

现有主菜单没有标题，按钮文字由 `GameInter/460` 等素材直接内嵌，无法把“师徒信息”安全改字，也没有“辅助设置”的对应内嵌文字素材。

### 设计

- 顶部增加居中的 `主菜单` 标题，保留右上角关闭按钮。
- 窗口高度只增加到容纳七个按钮和标题所需的最小尺寸，继续锚定在韩版主面板右上方。
- 七个按钮统一使用项目现有 `Interface.Zl` 通用金边按钮皮肤和运行时文字，避免混用内嵌文字素材：
  1. 环境设置
  2. 队伍信息
  3. 爆率查询
  4. 玛法排行榜
  5. 宠物状态
  6. 辅助设置
  7. 结束游戏
- 业务入口全部复用现有窗口：
  - 爆率查询：`GameScene.Game.RateQueryBox`，遵守现有 `RateQueryShowCheck`。
  - 辅助设置：`GameScene.Game.BigPatchBox`，观察者状态沿用现有限制。
  - 其余五项保持原处理逻辑。

### 验收

- 标题完整显示，关闭按钮不遮挡。
- 七个按钮外观一致、文字正确、点击区域与画面一致。
- 爆率查询和辅助设置分别打开已有对应窗口。
- 不再显示或调用“师徒信息”。

## 4. 韩版底部 IP 行模式显示

### 现状

现有 `AttackModeLabel` 与 `PetModeLabel` 已由 `AttackModeChanged()` 和 `PetModeChanged()` 更新，但韩版构造时将两者设置为不可见空尺寸。

### 设计

- 在 `GameInter/50` 的 `IP` 行启用两个现有标签。
- 左侧标签显示 `User.AttackMode.Lang()`，右侧显示 `User.PetMode.Lang()`。
- 使用青色、黑色描边、垂直及水平居中，与参考图一致。
- 只显示状态，不增加新的点击切换入口，不改变快捷键和封包逻辑。

### 验收

- 登录后 `IP` 行同时显示人物攻击模式和宠物控制模式。
- 使用现有快捷键切换模式后，文字立即同步刷新。
- 不遮挡 HP、MP、职业、等级或右侧功能按钮。
