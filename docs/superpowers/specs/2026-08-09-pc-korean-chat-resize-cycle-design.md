# PC 韩版聊天框四级缩放循环设计

## 目标

修正韩版聊天框两个大小切换按钮功能重复的问题，恢复由底部三角按钮统一控制的多级缩放行为，并让右侧滚动条和背景透明度与参考界面一致。145 界面保持不变。

## 已确认行为

1. 初始状态为最大聊天框，底部三角按钮朝下。
2. 连续点击底部三角按钮时，状态依次为：最大 → 缩小一级 → 缩小二级 → 缩小三级 → 隐藏聊天框。
3. 前四个可见状态中按钮始终朝下；隐藏聊天框后按钮改为朝上。
4. 隐藏状态保留底部聊天输入栏及三角按钮。再次点击后恢复最大聊天框，按钮改回朝下，并重新开始循环。
5. 删除或隐藏顶部重复的聊天框大小切换按钮，不保留第二套状态入口。
6. 右侧滚动条轨道随四个可见高度同步变长或变短；滑块仍由现有消息总量、可见行数和滚动位置控制。
7. 聊天内容背景约 30% 不透明；文字、标签、边框、滚动条和按钮保持原有清晰度。

## 最小实现边界

- 复用现有韩版 `ChatDialog`、`ChatTextBox.ChangeButton`、消息历史、过滤、滚动和输入逻辑。
- 只增加一个明确的韩版高度级别状态及一个集中更新布局的方法；不引入通用皮肤或动画系统。
- 每次状态变化统一更新聊天框可见性、内容区高度、可见行数、滚动条高度、按钮方向和消息显示。
- 不修改 145 分支、小地图、服务端、移动端、`Mir3.ini` 或 `.ZL` 资源。

## 验证标准

- 静态契约先在当前重复按钮实现上失败，修改后通过。
- 四个可见高度严格递减，随后隐藏；隐藏后一次点击恢复最大高度。
- 每一级滚动条高度与内容区同步，消息仍能滚动到首尾。
- 背景约 30% 不透明但文字和控件未整体变淡。
- PC 双界面既有契约通过，`145Client` Release Rebuild 为 0 错误。
- 运行时最终外观和鼠标点击由用户在真实 Direct3D 客户端手动验收。
