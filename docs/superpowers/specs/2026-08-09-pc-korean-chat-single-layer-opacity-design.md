# PC 韩版聊天单层背景与透明度修正设计

## 目标

移除韩版聊天记录区底部隐约出现的第二层 UI 阴影，并把背景调整为约 30% 透明（即 70% 不透明），同时保持聊天四级缩放、隐藏恢复和输入逻辑不变。

## 已确认根因

- `ChatDialog.Korean.cs` 在聊天记录窗底部绘制 `GameInter/3502`。
- 独立的 `ChatTextBox` 同时绘制真正的输入栏 `GameInter/3503`。
- 两个相邻底栏形成重复层和阴影。
- 当前 `0.3F` 是 30% 不透明，而用户需要的是约 30% 透明。
- 当前韩版使用通用 `DXVScrollBar`。虽然已指定 `GameInter/3561`、`3562`、`3560`，但其滑块横向偏移、有效轨道高度和拖动计算仍采用通用滚动条参数，与参考图中的原版 `DXMirScrollBar` 不一致。

## 已确认方案

1. 韩版聊天记录窗不再绘制内部 `GameInter/3502` 底栏。
2. 独立的 `GameInter/3503` 输入栏保留，作为唯一底部输入 UI。
3. 聊天标题、消息背景和输入栏背景统一使用 `0.7F` 不透明度；文字、标签、边框、按钮和滚动条保持原清晰度。
4. 消息背景、文字区域和右侧滚动条向下延伸到聊天记录窗底部，填补移除内部底栏后的空间。
5. 右侧滚动条继续复用共享 `DXVScrollBar` 的数值、事件和拖动接口，但增加默认关闭的韩版原始布局参数；韩版启用 `GameInter/3561` 上箭头、`3562` 下箭头和 `3560` 圆形滑块，并使用原版的 2 像素滑块横向偏移及 40 像素轨道扣减。其他滚动条保持现有默认参数。
6. 四个可见高度仍为 268、218、168、118；随后隐藏，再点击恢复最大。每一级统一更新消息区高度、可见行数、滚动条控件高度和有效拖动轨道。
7. 不修改经验悬停、145界面、小地图、服务端、移动端、`Mir3.ini` 或 `.ZL` 资源。

## 验证标准

- 韩版运行路径中只剩一个可见底部输入背景，即 `ChatTextBox` 的 `GameInter/3503`。
- `GameInter/3502` 不再作为聊天记录窗内部底栏构造或显示。
- 四级高度下，消息区和滚动条都延伸到距聊天窗底部约 1～2 像素处，并保持同步变长、变短。
- 韩版滚动条的箭头、圆形滑块、横向偏移和拖动范围与现有 `DXMirScrollBar` 原版实现一致；拖动、点击轨道、上下按钮和鼠标滚轮均能控制现有聊天记录索引。
- `DXVScrollBar` 新增参数的默认值保持通用控件原行为，145聊天和其他窗口不发生视觉或交互变化。
- 背景为 `0.7F`，文字和交互控件未整体变淡。
- 聊天缩放、经验悬停及 PC 双界面回归契约通过，Release Rebuild 为 0 错误。
- 真实 Direct3D 阴影消失和透明度观感由用户手动验收。
