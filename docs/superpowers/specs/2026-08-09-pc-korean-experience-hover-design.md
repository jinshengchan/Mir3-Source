# PC 韩版经验条悬停提示设计

## 目标

韩版底部 HUD 保持 `GameInter/51` 细长经验槽和 `GameInter/56` 横向进度填充；经验百分比不常驻显示，只在鼠标指向细长经验条时提示精确格式 `[经验] xx%`。

## 根因与最小方案

- 当前韩版 `ExperienceBar` 设置了 `PassThrough = true`，导致经验条不能成为悬停提示目标。
- 当前 `GameScene.ExperienceChanged()` 给所有界面写入相同的“当前经验/最大经验”提示，不符合韩版百分比格式。
- 仅让韩版经验条接收鼠标悬停，并在经验变化时为韩版设置 `[经验] {百分比:0%}`；145 分支保持原提示。
- `ExperienceLabel` 继续隐藏，不在 HUD 中常驻绘制经验文字。
- 不改变 `GameInter/51`、`GameInter/56`、经验计算或进度填充布局。

## 验证标准

- 韩版经验条不再穿透鼠标，悬停提示为 `[经验] xx%`。
- 百分比限制在 0%～100%；没有下一等级经验值时显示 100%。
- 经验文字不常驻显示。
- 145 界面原经验提示、经验槽和其他 HUD 行为不变。
- 专项契约与既有 PC 双界面契约通过，Release Rebuild 为 0 错误。
