# PC 场景移动、聊天边界与怪物信息修正设计

## 目标

在不改变 145 界面、服务端、移动端和资源文件的前提下，修正 PC 客户端韩版界面的三个已确认问题：斜向移动时树木/房屋半透明阴影闪烁、聊天记录区遮挡输入框、怪物信息窗口的显示行为与视觉参数不符。

## 已确认原因

- `145Client/Models/UserObject.cs` 只对上下左右移动的 `x/y` 偏移执行偶数像素对齐；斜向移动分支明确跳过，因此半透明场景像素在奇偶坐标间变化。
- 韩版聊天记录窗口底边紧贴输入框，而 `GameInter/3503` 输入框组合素材从输入控件顶部向上占用 8px；两层视觉区域重叠。
- `GameScene.Process()` 每帧持续用鼠标/焦点怪物刷新 `MonsterBox`，尚未把人物移动状态作为隐藏条件。
- `MonsterDialog` 信息文字仍为 8F，内容背景为 85%。

## 设计

1. 在 `UserObject.UpdateFrame()` 的现有移动像素修正处，让斜向移动和直向移动统一执行 `x -= x % 2; y -= y % 2;`。不修改地图素材、阴影素材、混合模式或其他对象绘制路径。
2. 韩版聊天记录窗口相对输入框整体上移 8px；同步修改默认位置和尺寸循环后的重定位，保持四级高度、滚动条和隐藏循环不变。
3. `GameScene.Process()` 在人物处于 `MirAction.Moving` 或 `MirAction.Pushed` 时隐藏怪物窗口并跳过当帧怪物赋值；人物停止后，若鼠标或焦点仍是有效怪物，继续由原逻辑恢复显示。鼠标移出不主动清空，ESC 和对象移除仍保持原行为。
4. `MonsterDialog` 仅将内容背景透明度改为 70%，信息文字从 8F 调整为 9F；三角按钮保持 9F，边框、血条和文字本身不随背景透明。

不新增资源、不修改 `Mir3.ini`、不修改服务端和移动端。正式实机确认前不重复创建备份。

## 成功标准

- 斜向连续移动经过树木、房屋时，场景与半透明阴影使用偶数像素偏移，不再奇偶闪烁。
- 韩版聊天四级高度下，记录窗口底边与输入框组合素材顶部至少相隔 8px；循环和隐藏功能保持可用。
- 人物移动或被推动时怪物信息隐藏，停止后仍指向有效怪物可恢复；鼠标移出不消失。
- 怪物内容背景为 70%，信息文字为 9F，无裁剪。
- 专项契约由 RED 变 GREEN，既有 9 个 UI 契约仍为 GREEN，`145Client.csproj` Release/AnyCPU 重建 0 error。
