# PC 韩版聊天输入区加长加高设计

## 目标

在不移动聊天模式按钮和右侧三角按钮的前提下，将韩版中间深色文字输入区调整为局部坐标 `(48,5)`、尺寸 `308x28`，使其更长、更高并填满两个按钮之间的可用区域。

## 设计

- `ChatTextBox` 总尺寸继续保持 `400x38`。
- `ChatModeButton` 继续位于 `(0,0)`，`ChangeButton` 继续位于 `(356,0)`。
- 韩版 `TextBox` 从 `(60,8)、295x20` 改为 `(48,5)、308x28`。
- 输入区右边缘为 `48 + 308 = 356`，正好停在三角按钮左边，不与其重叠。
- 仅影响韩版构造路径；145 输入框仍为 `560x20` 并沿用原位置。

## 明确排除

- 不进行 EXE 文件大小优化。
- 不修改 `FodyWeavers.xml`、`145Client.csproj`、依赖嵌入规则或调试符号设置。
- 不修改资源、三档缩放循环、回车隐藏、聊天位置及 `Mir3.ini`。

## 验收标准

- 聚焦源码契约先因缺少 `(48,5)、308x28` 而 RED，修改后 GREEN。
- 全部 PC 双界面源码契约通过，145 路径断言保持。
- Release 构建零错误；只在客户端关闭后覆盖 `Mir3.exe`。
