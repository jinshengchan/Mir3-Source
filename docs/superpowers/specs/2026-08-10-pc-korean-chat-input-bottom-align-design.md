# PC 韩版聊天输入栏下移与输入区右移设计

## 目标

让韩版聊天输入组合整体向下移动 `18px`，靠近底部主界面；同时把输入文字区及其深色背景从局部 `X=2` 右移到 `X=60`，从左侧聊天模式按钮右边开始。

## 选定方案

- 保持 `ChatTextBox` 的 `400x38` 尺寸及内部素材结构不变。
- 在韩版界面布局分支中，仅将整个 `ChatTextBox` 的纵坐标增加 `18px`；聊天记录框继续相对 `ChatTextBox` 顶部定位，因此与输入栏保持现有相邻关系并同步下移。
- `ChatModeButton` 仍位于局部 `(0,0)`，右侧 `ChangeButton` 仍位于局部 `(356,0)`。
- `TextBox` 仅把局部位置由 `(2,8)` 改为 `(60,8)`；其 `295x20` 尺寸不变，右边缘为 `355`，不会覆盖从 `X=356` 开始的三角按钮。
- 同步修正 `OnParentChanged` 的韩版初始定位，避免首次构造与后续布局出现位置跳动。

## 保持不变

- `218 -> 166 -> 118 -> 隐藏 -> 218` 循环及三角方向不变。
- 两次回车隐藏输入框的行为不变。
- 聊天模式按钮、三角按钮的素材、尺寸和命中范围不变。
- 145 界面的布局和交互路径不变。
- 不修改资源文件和 `Mir3.ini`。

## 验收标准

- 韩版 `ChatTextBox` 相对底部主界面的最终纵坐标为 `MainPanel.Location.Y - ChatTextBox.Size.Height + 18`。
- 韩版输入文字区局部坐标为 `(60,8)`，左侧聊天模式按钮不再被深色输入背景覆盖，且不与右侧三角重叠。
- 聚焦契约先 RED 后 GREEN；所有现有 PC 双界面源码契约继续通过。
- Release 构建零错误；只在客户端关闭后覆盖 `Mir3.exe`，且部署前后 `Mir3.ini` 哈希一致。
