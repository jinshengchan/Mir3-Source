# PC 韩版职业技能列表窗口设计

## 目标

仅在 PC 客户端选择“韩版界面”时，将现有魔法技能树改为参考图所示的纵向列表窗口。145 界面继续使用现有技能树，不改变布局、素材、分类或交互。

韩版窗口展示当前角色职业的全部技能，包括尚未学习的技能；顶部按钮按该职业实际存在的技能分类动态生成，不固定按钮数量。

## 数据与分类规则

- 先按 `MagicInfo.Class == MapObject.User.Class` 筛选当前职业技能。
- 再按 `MagicInfo.School` 生成顶部分类和分类内列表。
- 沿用现有技能树的合并规则：`WeaponSkills`、`Neutral`、`Passive`、`Unconditional` 合并到同一个基础/武技分类。
- 其他技能学校按实际数据分别生成分类；没有技能的分类不创建按钮。
- 分类按钮按现有 `MagicSchool` 的稳定顺序排列，基础/武技分类优先。
- 分类内技能按首次学习等级 `NeedLevel1` 升序排列；等级相同时按技能名称稳定排序。
- 切换分类只刷新当前列表，不改变角色职业，也不展示其他职业技能。

## 界面结构

- 保留参考图的金色窗口边框、标题区、关闭按钮、顶部分类按钮区、纵向技能列表和右侧滚动条。
- 顶部分类按钮数量和宽度根据当前职业的非空分类动态排列。
- 每个技能条目包含：技能图标、技能名称、要求等级、学习/熟练度进度区域。
- 一屏显示固定数量的完整条目；多余技能通过右侧滚动条和鼠标滚轮查看。
- 韩版专用界面素材和技能图标以独立资源映射加载，不覆盖当前 `UI1.Zl`、`MIcon.Zl` 或 145 界面使用的资源。
- 优先从 `D:\Video\英雄客户端\Data` 复用与参考图匹配的素材；若某个分类没有专用按钮图标，则使用该技能学校当前已有图标，不用无意义占位图。

## 技能状态与交互

- 未学习技能仍显示在列表中，要求等级使用红色文字；条目不可设置快捷键，也不可触发已学习技能操作。
- 已学习技能显示当前技能等级和熟练度进度，并复用现有技能悬停说明、鼠标操作和快捷键设置逻辑。
- 角色学习新技能、技能升级或熟练度变化后，只刷新受影响条目的状态，不重建145技能树。
- 打开窗口时默认选择当前职业第一个非空分类；同一次游戏运行期间再次打开时保留最后选择的有效分类。
- 当前分类因数据变化失效时，回退到第一个非空分类；无可用技能时显示空列表，窗口仍可正常关闭。

## 源码边界

- 保留 `MagicDialog` 作为 `GameScene` 的统一入口，避免改动所有调用者。
- 在 `MagicDialog` 构造时根据 `GameScene.Game.KoreanInterface` 选择现有145技能树或韩版列表。
- 韩版列表构建和条目控件放入独立的 `MagicDialog.Korean.cs` partial 文件；现有145构造和行为只做启用分支所需的最小调整。
- 复用现有 `MagicInfo`、`ClientUserMagic`、`RefreshAll`、悬停说明和快捷键数据，不增加服务端协议或数据库字段。
- 不修改安卓客户端、服务端、登录界面、聊天窗口或其他韩版窗口。

## 资源策略

- 不直接替换 `D:\Debug\4月18日更新\Client\Data\UI1.Zl` 或 `MIcon.Zl`。
- 如需引入英雄客户端素材，使用新的韩版技能窗口资源文件名，并在 `LibraryFile` 与 `Libraries.LibraryList` 中增加对应映射。
- 只复制实际引用的资源包；若目标目录已存在同名文件，正式覆盖前才备份该文件。
- `Mir3.ini` 不修改、不覆盖。

## 验收标准

1. 145 界面打开技能窗口时，布局、分类按钮、技能树和操作与当前版本一致。
2. 韩版界面打开技能窗口时，显示列表式窗口，不再显示145技能树。
3. 韩版顶部按钮数量等于当前职业实际存在的非空技能分类数量。
4. 每个分类只显示当前角色职业且属于该分类的技能。
5. 未学习技能可见，并以红色显示要求等级；不能设置快捷键。
6. 已学习技能的等级、熟练度、悬停说明和快捷键操作正常。
7. 技能图标与数据库 `MagicInfo.Icon` 对应，无跨职业或错位图标。
8. 鼠标滚轮和右侧滚动条均能浏览超出可视区域的技能。
9. 窗口关闭、重新打开、切换分类、学习或升级技能时无黑屏、卡死或异常。
10. Release/AnyCPU 构建成功；部署只更新经确认的 `Mir3.exe` 和新增的韩版技能资源，不覆盖 `Mir3.ini`。
11. `CHANGELOG.md` 记录源码文件、资源文件、构建结果和部署文件的实际变化。

## 明确排除

- 不修改145界面的技能树样式。
- 不允许浏览或切换到其他职业的技能。
- 不新增职业、技能、服务端字段或网络封包。
- 不调整客户端文件大小优化、聊天 UI、怪物信息 UI 或其他无关功能。
