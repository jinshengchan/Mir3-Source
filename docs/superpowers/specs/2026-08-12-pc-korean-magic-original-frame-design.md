# PC 韩版魔法技能窗口原版边框设计

## 目标

仅在 PC 客户端选择“韩版界面”时，将当前通用 `DXWindow` 外框替换为韩版自带魔法技能窗口素材，同时保留当前动态职业分类、技能列表、滚动、技能操作与图标修正。145 界面保持原样。

## 素材组合

- 顶框按当前职业使用 `GameInter2.Zl`：战士 `800`、法师 `801`、道士 `802`、刺客 `803`。
- 列表主体使用 `GameInter2.Zl:810`。
- 顶框已包含职业标识和分类图标，不再额外裁切或重复绘制职业标识、分类按钮图片。
- 现有分类按钮改为透明点击区，位置与顶框素材中的分类图标逐一重合；按钮数量仍按当前职业实际存在的 `MagicSchool` 动态生成。

## 分层与交互

1. 韩版顶框与主体素材处于背景层，不接收鼠标。
2. 透明分类点击区处于顶框之上，继续复用现有分类选择、按下状态和列表切换逻辑。
3. 技能行和滚动条处于主体素材之上；不改变当前数据筛选、排序、点击、悬停、快捷键和滚动逻辑。
4. 窗口继续可移动、可关闭；关闭按钮应使用现有可正常点击的控件，并放在韩版顶框右上角对应位置。

## 保持不变

- 145 界面的 `MagicDialog` 技能树、分类按钮和资源映射。
- `LibraryFile.MagicIcon -> Data/KoreanMIcon.Zl` 与 `MagicIcon145 -> Data/MIcon.Zl` 的隔离。
- `AugmentEvilSlayer` 在韩版列表中仅显示回退到图标 `524`。
- 聊天框 Enter 行为、角色数量、数据库、服务端、移动端、`Mir3.ini` 和所有 `.ZL` 文件。

## 最小改动范围

- `145Client/Scenes/Views/MagicDialog.Korean.cs`
- `.diagnostics/test_pc_korean_magic_list_contract.ps1`
- `CHANGELOG.md`

不修改 `MagicDialog.cs`，除非实现过程中证明现有共享窗口层无法在韩版分支关闭；遇到该情况先停止并重新确认，不自行扩大范围。

## 验收标准

- 韩版窗口使用完整 `800-803 + 810` 素材组合，不再显示通用金色 `DXWindow` 外框。
- 职业标识位于原韩版顶框位置，无额外裁切错位。
- 分类图标只绘制一层，所有实际分类均可点击，点击区域与图标一致。
- 技能列表、滚动条、未学/已学状态和灵魂分裂图标正常。
- 145 界面无源码和行为变化。
- 专项契约先 RED 后 GREEN；Release/AnyCPU 构建 0 错误。
- 正式覆盖前不重复创建备份；使用现有回滚备份，且不改写 `Mir3.ini`。
