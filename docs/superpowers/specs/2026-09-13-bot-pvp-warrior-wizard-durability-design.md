# 假人主动攻击、职业技能与装备耐久设计

## 目标

本次在服务端完成五项已确认行为：

- 增加“假人主动攻击真人”设置；开启后，假人在没有合适怪物目标时主动攻击视野内的真人。
- 假人战士不再使用野蛮冲撞。
- 假人法师不再长期只使用火球术和大火球，在符合场景的可用攻击技能之间轮换。
- 假人战士能够按服务器原有蓄力机制使用烈火剑法、莲月剑法和屠龙斩。
- 假人武器、防具、首饰等普通装备不再因战斗掉持久；药品、毒粉、护身符、火把及钓鱼装备继续正常消耗。

本次只修改假人相关的服务端行为，不修改客户端、数据库结构、地图数据、技能数值、真人角色行为或部署目录。

## 已确认规则

### 主动攻击真人

新增 `Config.BotAttackPlayers`，默认值为 `false`。服务端“假人系统配置”窗口增加“主动攻击真人”复选框，读取和保存该配置；运行中的假人在下一次行为 Tick 使用最新值，不要求重启假人系统。

目标优先级固定为：

1. 受击反击、攻城战、低血逃跑等现有高优先级行为保持不变。
2. 已锁定或新发现的可攻击怪物优先。
3. 仅当没有合适怪物目标且开关开启时，选择视野内距离最近的可攻击真人。
4. 没有真人候选时进入原有恢复、寻怪或漫游流程。

如果假人正在追击真人，而视野内出现合适怪物，假人切回怪物。真人候选必须满足：不是假人自身、不是其他假人、存活、可见、同地图、在最大视野范围内、不处于安全区或安全地图，并且不是同队或同行会成员。最终攻击仍经过现有 `CanAttackTarget` 合法性判断。

主动攻击期间允许假人使用全体攻击模式，使近战和法术的服务器判定能够命中真人。为防止全体模式误伤，`PlayerObject.CanAttackTarget` 只针对开启该配置的假人增加同队、同行会保护；该保护同时覆盖真人及其宠物。关闭开关后，假人恢复现有动态攻击模式，不改变原有受击反击逻辑。

### 战士技能

假人战士不再调用 `ShoulderDash`。与目标距离大于一格时使用现有追击和寻路逻辑，不新增其他冲撞替代技能。

烈火剑法、莲月剑法和屠龙斩沿用服务器现有“两阶段”规则：

1. 技能已学习、达到等级、冷却完成且魔法值足够时，假人先调用现有 `Magic` 入口完成蓄力。
2. 对应 `CanFlamingSword`、`CanBladeStorm` 或 `CanMaelstromBlade` 状态就绪后，技能才进入下一次近战攻击候选。
3. 攻击命中后由现有 `Attack` 入口消耗蓄力状态并结算伤害。

三种技能在可用时轮换，不固定长期使用其中一种。翔空剑法及其他未点名战士技能保持现状。服务器已有的技能互斥冷却、蓝耗、蓄力有效期和伤害计算不修改。

### 法师技能

保留现有法师直接攻击技能候选、冷却、蓝量、施法距离和元素限制，仅替换会长期固定到最高伤害或最低蓝耗火球的选择策略：

- 少于三只可攻击怪物时，在已学习、冷却完成、蓝量足够的单体攻击候选中轮换，群攻技能不参与。
- 三只及以上可攻击怪物时，在符合条件的群攻候选中轮换；没有可用群攻时再回退到单体攻击候选。
- 所有合法法术都不可用时，沿用现有站位与无技能回退。

轮换只覆盖现有假人选择器已经支持的直接伤害候选，不新增火墙、传送、控制或辅助类技能，也不修改法师技能本身的服务器实现。

### 装备耐久

在通用 `DamageItem` 入口增加严格的假人装备豁免：当角色是 `IsBot`、网格是 `GridType.Equipment`，且槽位属于武器、防具、首饰等普通装备时，直接跳过持久扣减。

以下消耗明确不豁免：

- `EquipmentSlot.Medicament`
- `EquipmentSlot.Poison`
- `EquipmentSlot.Amulet`
- `EquipmentSlot.Torch`
- `GridType.FishingEquipment`
- 背包内通过耐久表示次数的物品

真人角色仍走原有 `DamageItem` 逻辑。假人死亡掉落装备的既有保护不在本次重复修改。

## 方案选择

采用外科手术式方案：在现有配置界面、假人目标选择、技能选择和统一耐久入口增加窄分支。

未采用以下方案：

- 将主动攻击合并进 `BotPvPStrategy`：该模块当前表达受击后的威胁、风筝和逃跑，把主动寻敌并入会改变既有反击语义。
- 重写统一职业技能调度器：超出五项需求，且会扩大到道士、刺客和现有技能优先级。
- 在每个伤害调用点分别跳过持久：调用点多且容易漏掉，统一入口的 `IsBot` 与槽位守卫更小、更可验证。

## 验证标准

严格执行 RED、GREEN 顺序：

1. 先新增聚焦契约并运行。当前代码必须因缺少配置/UI绑定、只反击不主动寻人、野蛮突进仍存在、战士蓄力技能缺失、法师最高伤害选择仍会固定技能、假人普通装备仍扣持久而失败。
2. 再做最小生产修改，重复运行聚焦契约并全部通过。
3. 重跑现有假人契约，至少包括 CPU/药水、阶段一、40级/刺客、道士/法师优先级、装备/金币/技能和死亡复活契约。
4. 构建 `ServerLibrary/ServerLibrary.csproj`；再用独立输出和独立中间目录执行 Server Debug/AnyCPU 构建，禁止覆盖活动服务端文件。
5. 扫描确认没有遗留临时调试日志、野蛮冲撞调用或超出范围的文件改动。

静态契约和构建只能证明代码结构与可编译性，不能代替联机验收。最终运行时应手工确认：

- 开关关闭时，假人不会主动攻击未先攻击它的真人。
- 开关开启、附近有怪物和真人时，假人优先怪物。
- 开关开启、没有怪物时，假人攻击最近的合法真人，但不攻击假人、队友、同行会成员或安全区角色。
- 战士不再野蛮乱冲，并能先蓄力后实际打出烈火、莲月和屠龙斩。
- 法师在单怪和三只以上怪物场景实际使用多种符合条件的攻击技能。
- 长时间战斗后假人普通装备持久不变，药品、毒粉、护身符、火把等消耗仍会下降。

本任务不部署、不启动或停止服务，也不声称静态验证等同于上述联机验收。
