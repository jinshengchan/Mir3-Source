# 假人管理紧凑按钮布局设计

## 目标

解决假人管理窗口放大后操作按钮随栏宽无限拉长的问题。按钮在宽窗口中保持紧凑，在窄窗口中仍能自动缩小并完整显示；输入框、列表和日志区域继续随栏宽伸缩。

## 布局规则

- 左栏操作按钮最大宽度为 180 像素。
- 右栏行为快捷按钮最大宽度为 220 像素。
- 右栏按档快速切图按钮最大宽度为 150 像素。
- 每行按钮整体在可用区域内居中排列，按钮之间保留现有间距。
- 当栏宽不足以容纳设定的最大宽度时，按钮等分缩小，禁止产生横向滚动或裁剪。
- 窗口继续允许调整大小；按钮达到最大宽度后不再随窗口继续拉长。
- 输入框、状态区域、假人列表和日志框维持现有随栏宽伸缩行为。

## 功能边界

- 只调整按钮行的尺寸和对齐，不修改任何按钮文字、点击事件或业务逻辑。
- 保持左栏快捷重复按钮已经移除，`全员回城 / 暂停 / 同步到左侧` 仍只位于右栏快捷操作区。
- 保持左右分组完整展开、无纵向重叠，右栏无横向溢出。
- 不修改正式配置、数据库、客户端或部署目录。

## 验收标准

- 在 `1380x780` 客户区：左栏操作按钮宽度不超过 180，右栏行为快捷按钮不超过 220，快速切图按钮不超过 150。
- 在更宽窗口中，三类按钮仍不超过各自最大宽度。
- 在较窄窗口中，按钮宽度自动缩小，所有按钮的左右边界仍位于所属栏内。
- 三类按钮行在所属可用区域内水平居中。
- 现有按钮点击处理程序和运行时快捷调节契约保持不变。
- 五组假人管理契约、ServerLibrary 构建和正常 Fody Server Rebuild 全部通过。

## 非目标

- 不增加每个分组框的手动拖拽。
- 不按比例缩放字体或控件高度。
- 不保存用户手动调整的窗口或分隔线位置。
