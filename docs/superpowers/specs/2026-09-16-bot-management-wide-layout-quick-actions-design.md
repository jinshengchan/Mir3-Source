# 假人管理 800px 左栏、双列排版与临时快捷操作设计

## 目标

在不改变假人战斗、补给、PK 合法性和永久配置语义的前提下：

1. 将假人管理左栏固定为 800px，并优化两栏内部排版。
2. 解决运行状态、较长标签和操作区域显示不全的问题。
3. 让“攻击性 ±10”“活跃度 ±10”“药水补给 ±5”立即影响当前运行中的假人，并提供非阻塞操作提示。
4. 快捷增减只在本次假人在线运行期间有效；停止假人或最后一名假人下线后恢复已保存基础值。

## 已确认问题与证据

- 当前左栏分隔位置固定为约 530px，左栏组框固定为 505px，字段行固定为 475px，无法利用更宽窗口，也导致状态文字和长标签容易截断。
- 左栏所有组均使用单列 `FlowLayoutPanel`，复选框宽度固定为 470px，产生大量纵向滚动和右侧空白。
- 运行时反射点击“攻击性 +10”得到：滑块从 50 变为 60，但 `Config.BotAggressionPercent` 仍为 50。当前按钮只修改控件，没有应用运行配置，也没有操作日志或面板提示。
- 攻击性、活跃度和最低 HP/MP 药水数量均由假人逻辑直接读取运行期 `Config`，不需要改写战斗或补给算法即可即时生效。

## 方案

### 1. 外层分栏

- `SplitContainer` 左栏目标宽度为 800px。
- 左栏最小宽度设为 800px；右栏保留不少于约 520px 的可用宽度。
- 初始窗口宽度和最小窗口宽度同步扩大，确保 800px 左栏不会再次挤掉右栏。
- 窗口放大时右栏获得剩余空间；左栏保持 800px，不按比例继续膨胀。
- 两栏继续保留独立纵向滚动。

### 2. 左栏双列排版

- 左栏组框宽度扩大到约 775px。
- 短字段、数值框和复选框按加入顺序每行两项排列，每项约占一半宽度。
- 以下内容保持整行：文件路径、长状态文字、按钮组、地图操作、假人列表、实时日志和操作日志。
- “自动行为开关”“等级奖励”“每秒恢复”“聊天、特修与回城”等组使用双列，减少高度和空白。
- “假人操作”中的运行状态使用整行可换行标签，不使用省略号截断。

### 3. 右栏与其他排版

- 右栏组框不再固定挤在左上角，宽度跟随右栏可用区域，统一左右边距和组间距。
- “运行状态统计”占满整行；统计文字和打怪状态标签随右栏宽度伸展、允许换行，完整显示两行统计和较长状态。
- “行为强度”四个滑块各占整行，标签、滑轨和百分比数值统一对齐，避免缩短可调范围。
- “经济控制”“性能调优”和“新增功能配置”中的短字段使用两列网格；奇数项的最后一项左对齐，不拉伸到异常宽度。
- “快捷操作”固定为两列三行，与用户截图一致；六个按钮等宽等高。
- “按档快速切图”固定为四列两行；八个等级按钮等宽，顺序保持 1–9、10–19、20–29、30–39、40–49、50–59、60–69、70+。
- 右栏纵向滚动仅在高度不足时出现，不允许横向滚动条遮挡控件。
- 只调整布局尺寸和容器，不重命名配置项、不删除现有按钮。

### 4. 快捷操作的即时生效与提示

- 第一次快捷增减前，记录以下四项已保存基础值：攻击性、活跃度、最低 HP 药水、最低 MP 药水。
- 每次点击：
  1. 在允许范围内计算新值；
  2. 更新对应滑块或数值框；
  3. 立即更新运行期 `Config`，但不写入 `Server.ini`；
  4. 写入操作日志；
  5. 在面板显示非阻塞提示，例如“攻击性临时调整为 60%，停止假人后恢复”。
- 药水 `+5/-5` 同时调整最低 HP 和最低 MP 药水数量，并在提示中显示两个结果。
- 达到上下限时不重复应用，提示“已达到上限”或“已达到下限”。
- 不为连续点击弹出 MessageBox，避免阻塞快速调整。

### 5. 临时值生命周期

- 快捷增减不自动持久化。
- 执行“停止假人”时清除临时调整，并恢复首次调整前记录的基础值。
- 单个假人陆续下线时不影响剩余在线假人；最后一名假人下线时清除临时调整并恢复基础值。
- 如果 GM 明确点击“保存配置”，当前界面值写入永久配置，并成为新的基础值；临时调整标记随之清除，之后下线不会回退到保存前的旧值。
- 服务端重启后仍以已保存配置为准，不恢复上次运行期临时值。

## 错误处理

- 快捷应用失败时恢复本次点击前的控件值和运行值，并在操作日志和面板提示中显示失败原因。
- 恢复基础值必须幂等：重复停止或重复收到最后一名假人下线事件不得反复改变数值。
- 临时值的读取与更新沿用现有管理锁，避免 UI 线程和假人线程同时更新产生中间状态。

## 修改范围

预计仅修改：

- `Server/Views/BotConfigView.cs`
- `Server/BotManager.Management.cs`
- `Server/BotManager.cs`
- `Server/BotManager.Support.cs`
- 现有假人管理 UI、运行时和操作契约脚本

不修改：

- 战斗目标选择、PK 安全区/队伍/行会/假人/宠物保护
- 药水购买与使用算法
- 数据库结构、客户端、部署目录、正式配置和正式进程

## 验收标准

- 1380px 客户区下左栏为 800px，右栏不少于约 520px，右栏内容可见。
- 左栏短控件按每行两项排列；整行内容不被拆分；运行状态与统计文字完整显示。
- 右栏状态和滑块整行显示，三组短字段双列显示，快捷操作为两列三行，等级切图为四列两行。
- 6 个快捷按钮均能改变运行期有效值，并产生操作日志和面板提示。
- 快捷操作不写入永久配置；停止假人或最后一名假人下线后恢复基础值。
- 点击“保存配置”后当前值成为新基础值，下线不回退到保存前值。
- 原有五组假人管理契约通过，并新增布局、快捷操作、恢复和保存升级基础值的回归断言。
- `ServerLibrary` 与正常 Fody `Server` 构建无错误；新产物可启动并通过反射布局检查。
- 不部署、不修改正式配置、不启动或停止正式服务。
