# 地图坐标按钮与缩放设计

## 目标

- 地图坐标窗口及其弹窗中的按钮统一使用 9pt Microsoft YaHei UI 常规字体。
- 底图缩放保持 `MiniMap.Zl` 图片原始宽高比，不再按地图格子宽高拉伸。
- 底图使用高质量双三次插值；坐标点、选择区和网格仍按最终画布尺寸映射。

## 边界

- 只修改 `LibraryEditor/MapCoordinateForm.cs` 和 `LibraryEditor/MapCoordinateCanvas.cs`。
- 不修改地图、数据库、`MiniMap.Zl` 和主资源预览缩放逻辑。
- 无底图时继续使用地图格子尺寸和黑色坐标画布。

## 验收

- 900×600 底图在任意缩放级别保持 3:2。
- 放大后底图不再发生宽高比例失真，并使用高质量插值。
- 所有地图坐标功能按钮字号一致，长文字不截断。
- Debug 构建及真实地图加载通过。
