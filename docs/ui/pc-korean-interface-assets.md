# PC 双界面资源清单

本文记录 PC 韩文界面实际复用的客户端内置资源。资源仅从现有 `Data\GameInter.ZL`、`Data\UI1.ZL` 和 `Data\Interface.ZL` 读取，不新增或覆盖资源文件。

## 韩文 HUD

| 功能 | 资源 | 尺寸 | MainPanel 相对坐标 |
| --- | --- | --- | --- |
| 底部 HUD | `GameInter / 50` | 1024 x 68 | `(0, 0)` |
| 经验框 | `GameInter / 51` | 992 x 10 | 水平居中，Y=`3` |
| HP 填充 | `GameInter / 52` | 220 x 8 | `(35, 22)`，按 `User.CurrentHP / Stats[Health]` 横向裁剪 |
| MP 填充 | `GameInter / 54` | 220 x 8 | `(35, 36)`，按 `User.CurrentMP / Stats[Mana]` 横向裁剪 |
| 经验填充 | `GameInter / 56` | 980 x 4 | 在 `/51` 内居中，按 `User.Experience / User.MaxExperience` 横向裁剪 |
| 中央标签图 | `GameInter / 60..66` | 已核验 | CL/LV/FP/CP/DC/AC/MAC 框位 |

经验不使用 `GameInter / 58`。未暴露精确 FP/CP 模型字段，因此对应数值保持空白；DC/AC/MC 等现有属性仍由 `GameScene` 的刷新路径绑定。

## 韩文聊天

聊天构造使用 `LibraryFile.GameInter`，不使用 `GameInter2` 或 `Interface / 150`：

- 外框/输入：`3500 (380x48)`、`3502 (380x60)`、`3503 (380x38)`。
- 标签顺序：全部 `3511/3510`、一般 `3516/3515`、队伍 `3521/3520`、师徒 `3536/3535`、门派/行会 `3526/3525`、系统 `3531/3530`、同盟 `3506/3505`。
- 关闭：`3545`；展开/收起：`3542/3552`；滚动条：`3560/3561/3562`。
- 输入模式：本地 `3573`、私聊 `3568`、组队 `3523`、行会 `3528`、喊话/世界 `3578`。观察者模式保留文字兼容路径，不伪造素材。

聊天历史、过滤、滚动、回车发送、私聊、物品链接和释放行为继续复用当前 145 实现。`ChatBox` 位于输入框上方，输入框位于主 HUD 上方；快捷栏位于主 HUD 上方并保持 X=`0`。小地图不在本次改动范围内。

## 共享资源与预检

背包、人物界面、小地图和通用窗口继续使用现有 `UI1 / 1210, 1220, 1280, 1486..1489` 与 `Interface / 200, 203`。`GameInterfaceTheme.HasRequiredKoreanAssets()` 在 `GameScene` 构造前核验实际依赖；缺失时沿用当前安全回退到 145 的路径。

## 验证边界

本次代码契约覆盖资源索引、尺寸、按钮矩形、菜单行和坐标关系。Direct3D 客户端实际启动、像素级截图和鼠标点击仍需在真实客户端中人工复核。
